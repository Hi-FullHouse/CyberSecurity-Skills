# ⬆️ 阶段四：权限提升 (Privilege Escalation)

## 目标
从低权限用户提升至管理员/root权限，获取最高系统控制权。

## 核心技能清单
| # | 技能名称 | 难度 | 推荐工具 |
|:---:|:---|:---:|:---|
| 1 | Windows提权 | ★★★ | WinPEAS, PowerUp, PrivescCheck |
| 2 | Linux提权 | ★★★ | LinPEAS, Linux Exploit Suggester |
| 3 | 内核漏洞提权 | ★★★★ | 漏洞利用代码, MSF模块 |
| 4 | 服务漏洞提权 | ★★★ | 自定义脚本, AccessChk |
| 5 | 凭证窃取 | ★★★★ | Mimikatz, Lazagne, LaZagne |
